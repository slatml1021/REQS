# Kullanıcı testi formu

## Katılımcı bilgilendirmesi

Bu test, REQS tez prototipinin kullanılabilirliğini değerlendirmek içindir. Katılım gönüllüdür; kişisel veri, parola veya gerçek müşteri verisi girmeyin. Yanıtlar raporlamada toplulaştırılır. Katılımcı bu formu tamamlayarak anonim geri bildirim vermeyi kabul eder.

| --- | --- |
| Kod / rumuz |  |
| Tarih |  |
| Yazılım deneyimi (1-5) |  |
| Test ortamı/sürümü |  |

## Görevler

- [ ] Bir gereksinim ekledim ve düzenledim.
- [ ] İki gereksinim arasında ilişki kurdum, yönlülüğü değiştirdim.
- [ ] AHP, Wiegers veya Volere ile en az bir değerlendirme yaptım.
- [ ] Sonuç filtresini kullandım.
- [ ] Matris/ağ görünümünde ilişkiyi buldum.
- [ ] Bir gereksinimi güncelledim ve etki uyarısını inceledim.
- [ ] PDF raporu indirdim.

## Değerlendirme

Her maddeyi 1 (kesinlikle katılmıyorum) - 5 (kesinlikle katılıyorum) arasında puanlayın.

| İfade | Puan |
| --- | --- |
| Gereksinim ekleme ve düzenleme anlaşılırdı. |  |
| Önceliklendirme girdileri anlaşılırdı. |  |
| Matris ve ağ görünümü ilişkileri anlamama yardım etti. |  |
| Etki uyarısı karar vermeme yardım etti. |  |
| PDF rapor yeterince anlaşılırdı. |  |
| Sistemi tekrar kullanmak isterim. |  |

**Açık uçlu geri bildirim:** En zor adım neydi? Hangi iyileştirmeyi önerirsiniz?
**Değerlendirme yöntemi:** Her madde için ortalama/medyan raporlanır; açık uçlu yanıtlar tema bazında, kişisel bilgi içermeden özetlenir.
