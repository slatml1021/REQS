# Tez kaynak kütüphanesi

Bu klasörde yalnızca yasal olarak edinilmiş tam metin yayınlar saklanır. Bir yayın tez kaynakçasına alınmadan önce aşağıdaki bilgiler `kaynak-kayitlari.md` dosyasına işlenir:

1. Tam bibliyografik künye ve DOI
2. Yayıncı ya da kurumsal açık erişim adresi
3. Yerel PDF dosya adı
4. Tam metnin okunduğu tarih ve analiz notu

Telifli kitaplar veya yalnızca özet erişimi olan yayınlar buraya eklenmez; bunlar ancak kütüphane üzerinden edinildikten sonra kullanılabilir.
